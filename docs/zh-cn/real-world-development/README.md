通过真实场景、完整应用程序和共享待办事项，在整个软件开发生命周期中探索 GitHub Copilot。你将通过迭代来规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为桌游众筹提供平台，并以开发者为主题。团队的待办事项已整理为 GitHub 议题，随时可以着手处理。其中既有筛选和分页等功能工作，也有无障碍和编码规范等质量改进。

## 选择工作环境

无论在哪里工作，都可以使用 GitHub Copilot。根据自己的开发方式选择合适的环境。每个研讨会都有独立的设置步骤，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用画布，以及管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。通过 Copilot Chat 智能体模式、MCP 服务器和自定义智能体开展工作，无需离开编辑器。
